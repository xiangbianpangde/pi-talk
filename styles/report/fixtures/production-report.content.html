RELEASE VERDICT

正式汇报统一使用 report；其他 HTML 模式仅保留为显式高级能力

该设计系统把“好看的单页”升级为“可持续生成、可自动审计、可跨视口复用”的汇报基础设施。后续新增组件必须先进入规范与测试，不再通过临时内联样式扩张。
